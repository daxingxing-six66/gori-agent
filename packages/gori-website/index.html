A FEW THINGS TO KNOW.
开始之前。
Gori 适合谁使用？+
面向希望用自然语言处理 Linux 服务器日常操作的个人开发者。每个 SSH 工作区对应一个服务器目标，可以管理不同工作区和会话；当前产品不以集群编排或团队公网服务为目标。
需要在服务器上安装 Gori 吗？+
Gori 后端在你的电脑运行，通过 SSH 连接远程服务器。启用远端命令沙箱时，可能需要准备 Landlock 启动器或安装 Bubblewrap；具体能力与审批要求取决于远程环境。
可以用自己的模型吗？+
可以在设置中选择和配置模型供应商，也可以添加自定义供应商。模型请求与必要上下文会发送到该供应商；本机运行不代表所有数据都留在本机。
宣传站中的演示会操作我的服务器吗？+
不会。这些交互只使用浏览器中的预设示例，没有连接 Gori 后端、模型或 SSH 服务。安装 Gori 并配置自己的工作区后，才能执行实际操作。
Gori 是开源的吗？+
是，Gori 使用 MIT 许可证。Agent 与模型适配基础模块来自 pi，保留原作者声明。你可以在 GitHub 阅读代码、查看问题和参与项目。
