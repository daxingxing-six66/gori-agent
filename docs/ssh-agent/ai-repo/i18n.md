# Gori Web 国际化代码路由

本文索引 `packages/ssh-agent-web/` 的界面国际化与后端 Locale 联调实现。浏览器负责本地 UI 文案和每次请求的 Locale；后端负责公开异常、审批描述和 Tool 展示状态的翻译。用户输入、Workspace/Session 名称、路径、Provider/模型标识、LLM 内容、命令与 Terminal 输出始终保持原文。

## 运行时入口

- `app/layout.tsx` 在服务端解析请求语言，生成对应 Metadata，并把初始语言交给最外层 `LocaleProvider`。
- `features/i18n/server/request-locale.ts` 按 Cookie、`Accept-Language`、默认语言的顺序解析首屏 Locale。
- `features/i18n/components/locale-provider.tsx` 装配 `react-intl`，切换语言时同步 Cookie 与 `<html lang/dir/data-locale>`。
- `features/i18n/components/language-selector.tsx` 提供设置页中的中文、英文即时切换入口。
- `shared/api/client.ts` 从当前 `<html data-locale>` 读取语言，并为每个 REST 请求添加 `Accept-Language`；`apiUrlWithLocale()` 为 EventSource 生成携带 `locale` 的 URL。
- `features/chat/runtime/chat-event-stream.ts`、`features/sftp/components/use-workspace-events.ts` 与 `features/terminal/runtime/terminal-event-stream.ts` 分别为 Chat、Workspace、Terminal SSE 传递 Locale。切换显示语言时，它们随 Hook/面板 Effect 重建连接，避免继续消费旧语言的 SSE 投影。

## 类型与目录

- 使用统计提供独立的 `statistics.ts` 中英文目录，覆盖四个 Tab、筛选、图表、列表、空/错状态与缺失用量说明；数据查询与统计值不依赖界面语言。见 [statistics.md](./statistics.md)。

- `features/i18n/model/locale.ts` 定义 `SupportedLocale`、语言标签归一化、Cookie 契约和文本方向。
- `features/i18n/model/react-intl.d.ts` 将 FormatJS 消息 ID 限制为已登记的类型化 Key。
- `features/i18n/messages/zh-CN.ts` 聚合中文目录并导出 `MessageId`。
- `features/i18n/messages/en-US.ts` 以 `Record<MessageId, string>` 约束英文目录，缺失或多余 Key 会导致类型检查失败。
- 两种语言都按 `common/settings/workspace/session/chat/guard/provider/sftp/terminal` 拆分静态目录；不使用运行时动态加载。
- Session 服务器指标使用独立的 `server-metrics.ts` 双语目录，包括图标的无障碍名称、服务器收发方向、网卡、更新时间与采样/失败/过期状态；移除功能时可独立移除目录和聚合入口。见 [session-server-metrics.md](./session-server-metrics.md)。
- Deploy 计划标题、阶段摘要、构建步骤上一/下一命令浏览的控件标签、返回权限审批、启动中/失败反馈及执行/继续的自动 user 意图使用 deploy-task.ts 双语目录；命令、路径和服务名保留原文。
- Deploy 模块上拉面板（标题、关闭标签与单选控件的模块无障碍名称）、任务页、历史单行结果卡片（耗时提示与图形状态的无障碍名称）、日志工具栏、补充框与状态使用独立 `deploy-task.ts` 双语目录，旧计划审阅文案沿用 Chat catalog；阶段/字节来自结构化事实，不从翻译文本推断。
- Chat catalog 的 `deploy.planning.prompt` 使用 `{module}`，选择服务后由后端返回的 Discussion 模块名称填入。只补名称并保持原文，不翻译模块 ID/名称，不展示 Profile 或 hash；发布意图仍按 user 消息提交。
- 通用任务容器的放大、退出、收起和恢复使用独立的 `task-container.ts` 双语目录，由装配层把已本地化标签传入 `display` 契约；容器不依赖 Terminal 或未来 Deploy 的业务文案。见 [task-container.md](./task-container.md)。

## 文案职责

- 组件通过 `useIntl()` 处理按钮、标题、空状态、placeholder、`aria-label`、`title`、数字、日期和 ICU 复数。
- 本地校验与纯状态层返回稳定错误码或结构化状态，展示层负责翻译。
- Workspace 创建/编辑的分区说明、凭据状态、目录浏览和高级连接参数文案归入两种语言的 `workspace.ts`；编辑标题下的主机和端口保留原值，环境名称本地化。目录控件的简短可见动作和完整无障碍标签分别翻译。
- Dashboard、Guard 与 SFTP 的内容标题/说明、文件表格的操作列标签分别归入两种语言的 `sftp.ts`、`guard.ts`；沙箱检测的可展开限制说明标题归入 `workspace.ts`。SSH 凭据列表与秘密说明使用 `settings.ts` 的产品文案，不向用户解释内部存储或版本并发实现。
- 沙盒 Composer 仅提供原开关入口，标题“沙盒模式”/“sandbox”与功能介绍由 Session 消息目录提供；当前开关状态由呼吸灯及本地化无障碍标签表达。“只读”选择位于编辑会话的目录标题后方同一行，`session.sandbox.readOnlyOption/readOnlyHint` 提供复选框与信息图标悬浮说明，页首保留只读状态文案。`/sandbox` 机器命令不随语言变化，不提供只读命令。见 [session-sandbox.md](./session-sandbox.md)。
- Terminal Tab 标签的连接阶段使用双语 Terminal catalog，实时阶段使用独立 `terminal.panel.live` 短文案，不再把 resize owner、沙箱版本或路径拼接到顶栏；这些审计事实仍留在原数据契约中。

- `terminal.tool.reveal.description`、`terminal.tab.close/failed` 与 `terminal.tabs.label` 分别提供定位说明、标签关闭/失败与任务标签栏的双语无障碍文案；通用容器只接收已经本地化的展示字段，不依赖 Terminal catalog。
- 上传/下载详情的本地文件、远程文件、本地/远程路径或目录和进度标题归入双语 Chat catalog；路径和字节计数来自已有参数、结果详情与进度快照，不解析或改写后端本地化完成说明。常规完成说明不在传输卡片底部重复展示，失败、结果不确定及审批文案仍保留。
- SSH/Terminal 命令卡片的命令、终端输入、工作目录、超时、请求权限、观察预期及输出标签归入双语 Chat catalog；Terminal 卡片保留输入/快捷键和输出标题，不显示 action/expectation 的参数行；相关目录键保留，未知可见参数和枚举值仍原样展示。命令、路径、原始输出、退出码和信号不翻译，不从文本猜测执行结果。
- `shared/errors/api-error.ts` 直接保留后端按请求 Locale 返回的 `message`；断网、空响应等浏览器侧错误使用前端目录。前端不得根据本地化后的后端文本进行业务判断。
- `features/i18n/components/use-localized-error-message.ts` 提供稳定的错误格式化回调，避免语言切换触发依赖该回调的数据 Effect 重跑。

## 扩展语言

1. 在 `features/i18n/messages/` 下新增语言目录和聚合文件。
2. 让新目录满足 `Record<MessageId, string>`，并在 `messages/messages.ts` 注册。
3. 扩展 `SupportedLocale`、语言标签映射和 `LanguageSelector` 选项。
4. 运行 `tests/i18n-state.test.tsx`，确认 Key 完整、ICU 可解析且选择器可访问。

## 测试入口

- `tests/i18n-state.test.tsx`：Locale 优先级、语言标签归一化、Cookie、Catalog 完整性、ICU 解析和语言选择器。
- 各功能测试通过 `IntlProvider` 装配代表性组件，验证翻译不改变 Chat、Guard、SFTP、Terminal 与模型选择的业务状态。

Workspace/Session 共用的多目录字段、计数、勾选、移除、复制默认配置及保存说明使用两种 `workspace.ts` 中的 `sandbox.roots.*` Key；Session 编辑弹窗标题及 Terminal 重开说明使用 Session catalog，页首显示开启/只读/关闭状态。路径始终保留原文，计数及操作无障碍标签本地化。双语与新旧完整审计解析回归见 `tests/sandbox-writable-roots.test.tsx`。
