# Gori 项目介绍页

按《Gori 项目介绍页设计规范 v1.0》实现，使用 Sites 的静态站点结构。页面源码和可发布内容都在 `dist/`；无需 npm 安装、TypeScript 编译或后台服务。`.openai/hosting.json` 指定静态目录。

## 本地查看与修改

在仓库根目录执行：

```sh
python3 -m http.server 4188 --bind 127.0.0.1 --directory docs/site/dist
```

访问 http://127.0.0.1:4188 。`index.html` 管理内容，`styles.css` 管理布局和配色，`app.js` 管理截图查看，`config.js` 的 `GITHUB_REPO_URL` 是唯一仓库地址配置。地址未配置时所有 GitHub 按钮禁用；配置有效 GitHub 仓库 URL 后统一启用，新标签打开并设置安全外链属性。

这类静态网页可以理解为直接分发给浏览器的资源：HTML 类似页面模板，CSS 控制样式，JavaScript 处理浏览器交互。本页不需要 TypeScript，是因为没有复杂的应用状态或类型边界需要管理。

## 素材来源与边界

四张素材均来自 2026-09-11 在本机 3000 端口的“阿里云-测试”工作区中实际执行 `free -h` 时的截图。只裁切和转换图片格式，没有改写文字、数据或状态。观测高亮与“LLM 已观测至此”标签是当时捕获到的真实状态，介绍页没有连接服务器。

- `workspace.png`：对话与终端并排，1384 × 900。
- `conversation.png`：需求、工具调用与输入框，697 × 470。
- `terminal.png`：同一命令的调用和回显，1352 × 556。
- `observation.png`：实际观测范围与标签，622 × 150。

截图不包含服务器地址、账号、主机名、密钥或本地目录。保留了测试工作区别名与实际模型名称。随附原图仅作为视觉参考，未放入站点资源，因为其中包含私人运行环境信息。

测试操作包括只读 `free -h`，以及仅影响临时 PTY 的 `export PS1='$ '` 和清屏；未写入远程文件。后续 `vmstat -s` 审批超时，没有执行，也没有将其包装为成功结果。素材捕获于该请求出现之前。测试 PTY 已关闭，临时提示符随之失效。

## 验收记录

2026-09-11 本机浏览器检查：

| 宽度 | 结果 |

| 1440 | 三章按左右交替双列展示，图片大于正文区域，无横向溢出 |
| 1024 | 紧凑双列，32px 间隔，无横向溢出 |

| 390 | 单列，导航仅保留品牌与 GitHub，无横向溢出 |

浏览器验证了全部图片加载、章节锚点避开吸附导航、打开大图、关闭按钮、Escape、焦点进入及恢复、背景滚动锁定、点击图片保持打开。背景空白关闭已实现，自动化定位未完成可靠实测。无脚本时正文和图片默认可见，图片链接退化为直接查看；减少动态效果通过媒体查询关闭过渡和滚动动画，这两种降级已做源码检查。

`npm run check`、两个 JavaScript 文件的 `node --check` 通过。桌面与手机完整预览及第三章局部图保存在 `preview/`，不属于站点发布资源。

与规范的差异：按用户授权使用新采集的测试服务器截图，因此裁切坐标和比例随素材调整；第三章“查看大图”置于截图下侧框内，避免遮挡实际观测标签。未增加章节或更改产品文案。
